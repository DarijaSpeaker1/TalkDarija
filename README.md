# TalkDarija 🇲🇦

**TalkDarija** is a simple web app designed to help people learn and understand **Moroccan Darija**.

Our goal is to make Darija easier and more accessible for everyone — whether you're visiting Morocco, living here, or simply interested in Moroccan culture and language.

## 🌐 Live Website

https://talkdarija-tau.vercel.app/

## ✨ Features

* Learn Moroccan Darija
* Discover useful words and expressions
* Simple and beginner-friendly interface
* Accessible on desktop and mobile

## 🎯 Our Goal

We want to help more people communicate with Moroccans and discover the beauty of Moroccan Darija.

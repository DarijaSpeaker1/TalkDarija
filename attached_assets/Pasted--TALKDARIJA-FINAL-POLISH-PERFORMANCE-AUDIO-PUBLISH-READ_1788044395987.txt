# 14. AUTOMATIC AUDIO IN LISTENING EXERCISES

This is VERY important.

Some lesson levels/exercises should require listening.

For exercises designed around hearing/pronunciation:

### Automatically play the Darija audio when the exercise appears.

For example:

```text
┌─────────────────────────┐

       🔊

   "Bghit nakol."

What does this mean?

[ I want to eat ]
[ I am going home ]
[ I am tired ]
[ I am studying ]

└─────────────────────────┘
```

When the exercise opens:

1. Wait a very short moment if necessary.
2. Automatically play the Darija phrase.
3. Show the replay button.
4. Allow the user to replay it at any time.

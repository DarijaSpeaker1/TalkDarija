# 7. VOCABULARY QUALITY

Every vocabulary entry should ideally contain:

```ts
{
  darija: string,
  roman: string,
  english: string,
  category: string,
  example?: string
}
```

Example:

```text
Darija:
mzyan

Romanization:
mzyan

English:
good / nice

Category:
adjective

Example:
Had lmakla mzyana.
```

Do not create fake translations.

Do not randomly translate Darija into unnatural English.

# 9. DARija TRANSLITERATION

Be consistent.

Support common Moroccan Latin-number conventions:

```text
3 = ع
7 = ح
9 = ق
5 / kh = خ
ch / sh = ش
gh = غ
```

Do not force one spelling when multiple common spellings exist.

Where appropriate, mention variants.

Example:

```text
chno / shno
```

But do not confuse beginners by constantly presenting variants.

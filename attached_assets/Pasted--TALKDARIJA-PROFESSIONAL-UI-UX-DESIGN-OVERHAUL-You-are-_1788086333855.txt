# TALKDARIJA — PROFESSIONAL UI/UX DESIGN OVERHAUL

You are now the lead UI/UX designer for **TalkDarija**, a Moroccan Darija language-learning platform.

The application already has its core functionality. Your task is to **professionally redesign and polish the visual experience** without breaking any existing functionality.

## CRITICAL RULE

Do NOT rebuild the application from scratch.

Do NOT remove existing features.

Do NOT change the underlying learning logic unless absolutely necessary.

Preserve:

* onboarding
* placement test
* lessons
* course progression
* XP
* hearts
* diamonds
* streaks
* achievements
* vocabulary
* profile
* settings
* audio
* voice pronunciation
* listening exercises
* saved progress
* dark mode

This is a **UI/UX transformation**, not a functionality rewrite.

---

# 1. DESIGN GOAL

TalkDarija should feel like a real, professional language-learning product.

The design should communicate:

🇲🇦 Moroccan identity
🎓 Education
🎮 Gamification
✨ Modern technology
🗣️ Conversation
⚡ Speed and simplicity

The visual style should be:

**modern + playful + clean + premium + Moroccan**

Avoid making it look like a generic AI-generated website.

Avoid excessive gradients, excessive glassmorphism, excessive shadows, and unnecessary decorative elements.

---

# 2. BRAND IDENTITY

The brand is:

# TalkDarija

The interface should visually reinforce the name.

Use subtle Moroccan-inspired details without turning the application into a stereotypical Moroccan tourist website.

Good inspiration:

* subtle geometric patterns
* restrained Moroccan-inspired shapes
* clean modern typography
* small cultural details
* elegant use of Moroccan visual language

Do NOT cover the interface with Moroccan patterns.

The Moroccan identity should be subtle.

---

# 3. COLOR SYSTEM

Create a consistent design system.

Use a strong primary brand color based on the existing TalkDarija identity.

Use:

* primary
* secondary
* success
* warning
* error
* background
* surface
* text
* muted text
* border

Define them as CSS variables/design tokens rather than repeatedly hardcoding colors.

Example concept:

```text id="m6l6xj"
--color-primary
--color-secondary
--color-success
--color-warning
--color-error
--color-background
--color-surface
--color-text
--color-muted
--color-border
```

Maintain excellent contrast.

---

# 4. LIGHT MODE

Light mode should feel:

* bright
* clean
* friendly
* spacious

Avoid pure white everywhere.

Use subtle surface variations to create hierarchy.

Example:

```text id="b6l1k7"
Background
   ↓
Surface
   ↓
Card
   ↓
Interactive element
```

---

# 5. DARK MODE

Dark mode should NOT simply invert the light theme.

Create a properly designed dark theme.

Use:

* dark backgrounds
* slightly lighter cards
* readable text
* subtle borders
* carefully controlled brand colors

Avoid pure black backgrounds unless necessary.

---

# 6. TYPOGRAPHY

Choose a modern, highly readable font system.

Typography must work for:

* English
* French
* Arabic
* Darija Latin transliteration
* numbers

Create a hierarchy:

### Display

Large headings.

### Heading

Section titles.

### Body

Normal content.

### Caption

Small supporting information.

Do not use too many fonts.

Prefer one primary font family with appropriate weights.

---

# 7. SPACING

Create consistent spacing throughout the application.

Avoid:

* cramped cards
* random margins
* inconsistent gaps
* elements touching screen edges

Use a predictable spacing system.

Example:

```text id="0ip4z0"
4px
8px
12px
16px
24px
32px
48px
64px
```

---

# 8. CARDS

Redesign cards to feel modern.

Cards should have:

* consistent radius
* subtle border
* subtle shadow where appropriate
* clear hierarchy
* comfortable padding

Do not give every card a giant shadow.

---

# 9. BUTTONS

Create a consistent button system.

### Primary

Used for the main action.

### Secondary

Used for alternative actions.

### Ghost

Used for low-priority actions.

### Destructive

Used for dangerous actions.

Buttons should have:

* hover state
* active state
* disabled state
* focus state

Add subtle interaction animations.

# TALKDARIJA — COMPLETE WEBSITE BUILD SPECIFICATION

## ROLE

You are an expert senior full-stack web developer, UI/UX designer, React/TypeScript developer, and educational-app designer.

Build **TalkDarija**, a polished web application for learning Moroccan Darija (Moroccan Arabic), inspired by the **game-like learning experience and progression philosophy of Duolingo**, but with its own original branding, UI, content, illustrations, and implementation.

The application must feel like a **real, production-quality language-learning platform**, not a basic demo.

The user is a beginner in web development, so the code must be clean, understandable, modular, and well organized.

---

# 1. CORE PRODUCT

Website name:

**TalkDarija**

Purpose:

> Help people learn Moroccan Darija through short interactive lessons, exercises, repetition, progression, XP, hearts, achievements, and personalized learning.

Target users:

* Complete beginners
* People who know basic Darija
* Intermediate Darija learners
* Advanced learners
* Foreigners learning Moroccan Darija
* Moroccans who want to improve reading/writing in Latin-transliterated Darija

The website should support Darija written primarily in **Latin/Franco-Moroccan transliteration**, for example:

* salam
* labas?
* kidayr?
* chno smitek?
* fin sakn?
* bghit
* kanqra
* mzyan
* ma fhemtch

Use natural Moroccan Darija rather than Modern Standard Arabic.
